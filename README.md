# InkPrinta Landing Page

This is the front-end repository for the InkPrinta custom apparel landing page. 

## Running the Development Server

To start the local development server, simply run:

```bash
cd inkprinta-landing
npm install
npm run dev
```

Open your browser and navigate to the localhost port provided in your terminal (usually `http://localhost:5173` or `http://localhost:5174`).

## Deployment (Render)

This project is configured and optimized for free deployment on [Render](https://render.com/). 
When creating your **Static Site** web service on Render, use the following settings:
- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `dist`
